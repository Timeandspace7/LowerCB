# 下修盈亏测算

版本见 VERSION，发布记录见 references/releases.md。界面名称为“下修盈亏测算”。

## 输入与证据
识别证券代码、数量Q、面值M、买入价Pb、市场债价Pm、正股价S、现行转股价K0、假设下修价K1、卖债价Bs、卖股价Ps和费用。区分持仓、成交、计划与假设。数量未知仅给每张结果，不把空白当0或10张；演示数量标明“示例”。
更新原Excel前读取最新版本，保留用户数量、成本及费用，不用报价覆盖成本。未知费用以0作毛测算，标“未计费用”；利息及资金成本分列。
用户要求当前数据时联网核实行情、来源和北京时间，区分盘中与收盘；失败时明确历史快照时间，不称最新。固定参数数学情景不必刷新。
核实发行文件触发条件、计数起点、不下修承诺、会议日、所有定价下限、最终价、生效日、转股暂停、整股取整及零股返还和利息规则。触发不代表必修；假设价不代表当前生效价。

## 均价与底价
20日均价=20日成交额合计/成交股数合计；前1日均价同理。统一元、股，核实交易日和停牌及条款调整。不用收盘价平均或每日均价简单平均。完整交易日窗口不混入盘中数据。
仅当实际条款要求时，取两项均价较高者，并检查其他约束。股东会未定只称“滚动参考底价”，确定后按实际会议日前窗口重算。
数据舍入须标估算、披露精度；情景取分不得当正式规则。数据不足不得编造。

## 公式
- V0=M*S/K0；V1=M*S/K1。
- 现行市场溢价率=Pm/V0-1；下修后成本溢价率=Pb/V1-1；下修后情景溢价率=Bs/V1-1。明确分子和转股价口径，溢价率不是收益率。
- 目标溢价率p对应条件债价=V1*(1+p)，仅为情景，不是预测。
- 名义投入=Q*Pb+买入费用；非峰值占用，收益率非年化。
- 卖债盈亏=Q*(Bs-Pb)-买入费-卖债费-资金成本+该路径另行实收税后利息。
- 单笔股数n=INT(Q*M/K1)；剩余面值R=Q*M-n*K1。核实该券返还规则；分批转换逐笔取整。
- 转股盈亏=n*Ps+R+该路径税后利息-Q*Pb-买入费-转股卖股费用-资金成本。利息含实际零股应计息，不重复计入。
- 理论保本股价=Pb*K1/M（忽略取整/费用）。
- 实际保本股价=(Q*Pb+买入费+转股卖股费用+资金成本-R-该路径税后利息)/n，要求n>0。
- 卖债保本价=Pb+(买入费+卖债费+资金成本-该路径税后利息)/Q，要求Q>0。
- 收益率以买债本金加买入费用为分母；Q=0盈亏为0，收益率和保本价不适用。费用随成交额变化时按费率求根，固定金额表须注明局限。
零股本金不是额外利润。卖债与转股为替代路径，不能相加。新价须生效、可正常转股卖股才可用于执行；考虑交收时间及价格风险。

## 情景与节点
用户情景优先；默认债价85、90、93、95、100、110、120、145，全部是假设。展示不同债价的盈亏/溢价率、不同正股价和转股价的退出盈亏、不下修与修到底/未到底情景。展示保本点、上下0.10元及相邻有效报价，去重、排除负价；核实市场最小报价单位。
按三个节点更新：(1)董事会是否下修、承诺期、会议日；(2)会前重算均价、底价、行情和盈亏；(3)最终价、表决、生效日、转股安排、退出比较。未核实公告不得写已完成。不修则记本轮结果及承诺期。仅用户要求时另设定时任务。

## 脚本与交付
参考 references/input_example.json，全部为合成假设。运行 python scripts/calculate.py 输入.json 输出.json；--self-test检查边界。daily金额和股数必须是元、股，完整20交易日经外部证据核实；舍入精度写来源说明。
新建Excel时，按电子表格技能准备操作标记、主运行时和临时工作目录；将 scripts/calculate.py 和 scripts/export_excel.mjs 一同复制到临时目录，在该目录链接主运行时 node_modules，用主运行时Node执行临时目录的 export_excel.mjs 输入.json 输出.xlsx。脚本不联网；用户数据与公告证据由调用者核实。已有表按原结构编辑，不能用新表导出器覆盖。
至少包含“下修盈亏测算”“数据与节点依据”：可编辑参数、现行与假设指标、卖债/转股情景、保本点、均价明细及三节点依据。核心结果使用公式。用户数据/行情/文件身份不写入Skill源码。
检查核心值和缓存、Q=0/未知、多张数、费用变化、整股边界、公式错误，渲染检查排版，保存并交付Excel链接，不能只给文字或脚本。依赖不可用要明确报告。保留来源、时间、估算状态和风险边界。
